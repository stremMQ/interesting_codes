приложение троллинг:
  открывается окно с насущим вопросом и 2 кнопки "да" и "нет"

  если пользователь хочет нажать нет, то кнопка перемещается на рандомное место в окне, тем самым он не может на нее нажать и ему остаётся нажать на кнопку да

  программа реализована на языке Python через библиотеку tkinter
